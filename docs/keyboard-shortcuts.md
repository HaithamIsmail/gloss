# Keyboard shortcuts

On a Mac, use `⌘` where this page says `Ctrl`.

## Everywhere

| Keys | Action |
| --- | --- |
| `Ctrl K` | Open or close search (except inside a drawing, or with text selected in a page, where it makes a link) |
| `Esc` | Close a dialog or menu; stop linking text to a region |
| `←` / `→`, `Page Up` / `Page Down` (not typing) | Previous / next page in the same folder |
| `Alt ←` / `Alt →` (also while typing) | Previous / next page in the same folder |

**In search:** `↑` `↓` choose · `Enter` open · `Esc` close.

**Guided tour:** `→` or `Enter` next · `←` back · `Esc` skip.

## Pages

| Keys | Action |
| --- | --- |
| `/` | Block menu |
| `@` | Link another material or region |
| `$…$` | Inline formula (when you type the closing `$`) |
| `$$` on an empty line | Formula block |
| `:` + 2 letters | Emoji |
| `Ctrl B` / `Ctrl I` / `Ctrl U` | Bold / italic / underline |
| `Ctrl Shift S` | Strike-through |
| `Ctrl E` | Inline code |
| `Ctrl K` (text selected) | Make a link |
| `Ctrl Alt 1` / `2` / `3` | Section / Subsection / Heading |
| `Ctrl Alt 0` | Paragraph |
| `Ctrl Alt Q` | Quote |
| `Ctrl Shift 6` / `7` / `8` / `9` | Toggle list / numbered list / bullet list / check list |
| `Tab` / `Shift Tab` | Nest / un-nest block |
| `Ctrl Z` / `Ctrl Y` (or `Ctrl Shift Z`) | Undo / redo |
| `Enter` or `↓` in the title | Jump into the page |

**Start a line with** `#` `##` `###` (headings), `-` `+` `*` (bullets), `1.` (numbers), `[]` `[x]` (check list), `>`
(quote), ```` ``` ```` (code), `---` (divider), each followed by a space.

**Inline formula editor:** `Enter` keep · `Esc` cancel. **Formula block:** `Ctrl Enter` or `Esc` finish.

**Region comment:** `Enter` save · `Shift Enter` new line · `Esc` save.

## Annotated image pages

| Keys | Action |
| --- | --- |
| `Ctrl Z` / `Ctrl Shift Z` or `Ctrl Y` | Undo / redo region changes |
| `+` (or `=`) / `-` / `0` | Zoom in / out / fit |
| `Ctrl V` | Paste an image |

## Notebooks

| Keys | Mode | Action |
| --- | --- | --- |
| `Shift Enter` | both | Run, go to next cell |
| `Ctrl Enter` | both | Run, stay |
| `Alt Enter` | both | Run, insert cell below |
| `Esc` | edit | Command mode |
| `Enter` | command | Edit mode |
| `↑` `k` / `↓` `j` | command | Previous / next cell |
| `a` / `b` | command | Insert code cell above / below |
| `m` / `y` | command | Make markdown / code |
| `d` `d` | command | Delete cell |
| `z` | command | Restore deleted cell |
| `Tab` / `Shift Tab` | edit | Indent / dedent |
| `Ctrl /` | edit | Toggle comment |
| `Ctrl Space` | edit | Autocomplete |
| `Alt ↑` / `Alt ↓` | edit | Move line |

## Drawings

| Keys | Action |
| --- | --- |
| `Ctrl Enter` | Insert / save the drawing (drawing opened from a page) |

All of [Excalidraw's shortcuts](https://excalidraw.com) work in the canvas (`V` select, `R` rectangle, `O` ellipse, `A`
arrow, `L` line, `P` pen, `T` text, `Ctrl K` link…).
